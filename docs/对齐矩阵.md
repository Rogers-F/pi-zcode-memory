# 对齐矩阵

上游基线：ZCode 3.16.2 `apps/zcode-cli/packages/core/src`（逐文件 SHA-256 见 `NOTICE.md` 与 `test/fixtures/upstream-prompts.json` 的 `_provenance`）。
宿主基线：PI-Desktop 0.21.0（Electron 43.6.0 / Node 24.20.0）。

本表逐行对照上游行为，状态只有三种：

- **已实现**：行为一致，写明测试名。
- **等效替代**：宿主或运行时限制导致不能照搬，写明原因与测试名。
- **宿主不支持**：宿主做不到，写明宿主源码位置，不做假实现。

测试名格式为 `` `测试文件 › 测试标题` ``，`npm run check` 会核对文件与标题都存在。

## 替换表（提示词中唯一允许的差异）

| 差异 | 从 | 到 | 依据 |
| --- | --- | --- | --- |
| 产品名 | `CLAUDE.md` | `AGENTS.md` | PI-Desktop 的项目指令文件是 `AGENTS.md`；冠词随之调整（`a CLAUDE.md` → `an AGENTS.md`） |
| 路径 | 记忆根目录 | `~/.pi-desktop/zcode-memory/memories/projects/<slug>-<hash>/memory` | 宿主数据目录 |
| 路径 | 转录目录 | `~/.pi-desktop/zcode-memory/transcripts/<projectKey>` | 宿主数据目录 |

上游 14 段提示词逐字比对（`test/prompts.test.cjs`，基线由上游源码生成：`test/fixtures/upstream-prompts.json`）：记忆规则 default-index、记忆规则 semantic-recall、提取提示词（带清单 / 空清单）、Dream 提示词、代理持久记忆提示词 6 种（user / project / local × 空索引 / 有索引）、记忆清单行、选择器请求、召回附件。另有 4 段同样逐字比对：`# agentsMd` 索引外层、`context_prefix` 元用户包装、`<system-reminder>` 包装、Dream 一次性更新提示。

本插件新增、不属于上游的文字只有三段，单独列出且有测试：文本工具协议（宿主不返回工具调用）、选择器 JSON 输出说明（宿主不能传 JSON Schema）、`Task` 任务末尾的 `<persistent-agent-memory>` 外壳。
